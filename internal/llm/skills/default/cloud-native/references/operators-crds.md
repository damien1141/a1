# CRDs & Operators

## When to Build an Operator

| Need | Operator? |
|---|---|
| Codify operational procedures (backup, restore, failover) | Yes |
| Manage external resources (DB clusters, DNS, certs) | Yes |
| Implement domain-specific reconciler (e.g. ML pipelines) | Yes |
| Wrap a Helm chart for one-time deploy | No — use Helm directly |
| Simple deployment + service | No — just write YAML |

Operators shine when you'd otherwise need runbooks, cron jobs, or human action to reconcile state. The pattern: **declare desired state in a CR; controller reconciles actual state toward it**.

## API Type Definition (Go)

```go
// api/v1/database_types.go
package v1

import metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"

type DatabaseSpec struct {
	Engine  string `json:"engine"`
	Version string `json:"version"`
	Storage string `json:"storage"`
	Replicas int32 `json:"replicas,omitempty"`
}

type DatabaseStatus struct {
	Phase              string `json:"phase,omitempty"`
	Ready              bool   `json:"ready,omitempty"`
	Endpoint           string `json:"endpoint,omitempty"`
	ObservedGeneration int64  `json:"observedGeneration,omitempty"`
}

// +kubebuilder:object:root=true
// +kubebuilder:subresource:status
// +kubebuilder:subresource:scale:specpath=.spec.replicas,statuspath=.status.replicas
type Database struct {
	metav1.TypeMeta   `json:",inline"`
	metav1.ObjectMeta `json:"metadata,omitempty"`
	Spec   DatabaseSpec   `json:"spec,omitempty"`
	Status DatabaseStatus `json:"status,omitempty"`
}

// +kubebuilder:object:root=true
type DatabaseList struct {
	metav1.TypeMeta `json:",inline"`
	metav1.ListMeta `json:"metadata,omitempty"`
	Items []Database `json:"items"`
}
```

## Reconcile Loop — The Heart

The reconcile loop must be **idempotent** and **level-triggered** (not edge-triggered). Same input → same output.

```go
// internal/controller/database_controller.go
func (r *DatabaseReconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
	log := log.FromContext(ctx)

	// 1. Fetch the CR
	db := &mycompanyv1.Database{}
	if err := r.Get(ctx, req.NamespacedName, db); err != nil {
		if errors.IsNotFound(err) {
			return ctrl.Result{}, nil  // deleted; nothing to do
		}
		return ctrl.Result{}, err
	}

	// 2. Handle deletion via finalizer
	if !db.DeletionTimestamp.IsZero() {
		if controllerutil.ContainsFinalizer(db, finalizerName) {
			if err := r.cleanupExternal(ctx, db); err != nil {
				return ctrl.Result{}, err
			}
			controllerutil.RemoveFinalizer(db, finalizerName)
			if err := r.Update(ctx, db); err != nil {
				return ctrl.Result{}, err
			}
		}
		return ctrl.Result{}, nil
	}

	// 3. Add finalizer if missing
	if !controllerutil.ContainsFinalizer(db, finalizerName) {
		controllerutil.AddFinalizer(db, finalizerName)
		if err := r.Update(ctx, db); err != nil {
			return ctrl.Result{}, err
		}
	}

	// 4. Reconcile owned resources (StatefulSet, Service, Secret)
	sts, err := r.reconcileStatefulSet(ctx, db)
	if err != nil {
		return ctrl.Result{}, err
	}
	if _, err := r.reconcileService(ctx, db); err != nil {
		return ctrl.Result{}, err
	}

	// 5. Update status from observed state
	newStatus := mycompanyv1.DatabaseStatus{
		ObservedGeneration: db.Generation,
		Endpoint:           fmt.Sprintf("%s.%s.svc:5432", db.Name, db.Namespace),
	}
	if sts.Status.ReadyReplicas == *sts.Spec.Replicas {
		newStatus.Phase = "Running"
		newStatus.Ready = true
	} else {
		newStatus.Phase = "Creating"
		newStatus.Ready = false
	}

	if !reflect.DeepEqual(db.Status, newStatus) {
		db.Status = newStatus
		if err := r.Status().Update(ctx, db); err != nil {
			return ctrl.Result{}, err
		}
	}

	// 6. Requeue if not yet ready
	if !newStatus.Ready {
		return ctrl.Result{RequeueAfter: 10 * time.Second}, nil
	}
	return ctrl.Result{}, nil
}
```

## Operator SDK Commands

```bash
# Initialize
operator-sdk init --domain mycompany.io --repo github.com/mycompany/database-operator

# Create API
operator-sdk create api --group mycompany --version v1 --kind Database --resource --controller

# Generate CRD manifests + deep copy code
make manifests
make generate

make docker-build docker-push IMG=registry.example.com/database-operator:v1.0.0

make deploy IMG=registry.example.com/database-operator:v1.0.0
```

## RBAC for the Operator

Kubebuilder generates RBAC from `+kubebuilder:rbac` comments:

```go
// +kubebuilder:rbac:groups=mycompany.io,resources=databases,verbs=get;list;watch;create;update;patch;delete
// +kubebuilder:rbac:groups=mycompany.io,resources=databases/status,verbs=get;update;patch
// +kubebuilder:rbac:groups=mycompany.io,resources=databases/finalizers,verbs=update
// +kubebuilder:rbac:groups=apps,resources=statefulsets,verbs=get;list;watch;create;update;patch;delete
// +kubebuilder:rbac:groups="",resources=services;secrets,verbs=get;list;watch;create;update;patch;delete
```

Run `make manifests` to materialize these into `config/rbac/role.yaml`.

    metadata: { labels: { app: database-operator } }
    spec:
      serviceAccountName: database-operator
      containers:
        - name: manager
          image: registry.example.com/database-operator:v1.0.0
          args:
            - --leader-elect
            - --health-probe-bind-address=:8081
            - --metrics-bind-address=:8080
          livenessProbe:
            httpGet: { path: /healthz, port: 8081 }

            httpGet: { path: /readyz, port: 8081 }

          securityContext:
            allowPrivilegeEscalation: false
            readOnlyRootFilesystem: true
            capabilities: { drop: [ALL] }

## Reconciler Best Practices

1. **Idempotent** — running twice must equal running once. Don't depend on previous reconcile state.
2. **Level-triggered** — react to current state, not to events. The watch just triggers a reconcile.
3. **Owner references** — set on owned resources so they GC when the CR is deleted.
4. **Finalizers** — block deletion until external cleanup completes (cloud resources, S3 buckets).
5. **Status subresource** — separate `spec` (desired) from `status` (observed); update via `r.Status().Update()`.
6. **Events** — emit k8s events for significant transitions (`r.EventRecorder().Event(db, "Normal", "Created", "...")`).
7. **Leader election** — `--leader-elect` flag for HA; only one controller active.
8. **Use `envtest`** for unit testing controllers (real K8s API server in-process).
9. **Rate limit** — use `ratelimiter` to back off on errors for specific resources.
10. **Don't panic** — always return error; never let reconcile crash the manager.

## When NOT to Build an Operator

- You can do it with a Helm chart + a CronJob — do that instead.
- You're wrapping an external system with a stable API — use a `Provider` config CRD (Crossplane).
- You have <5 instances to manage — manual ops + runbook is cheaper.
- No one on the team can maintain Go + controller-runtime — pick a Python/Java operator SDK or skip.

## Alternatives

| Tool | Style | When |
|---|---|---|
| Operator SDK (Go) | Code-first, controller-runtime | Full control, performance |
| Kopf (Python) | Python decorators | Prototyping, team is Python-heavy |
| Shell-operator | Bash scripts | Simple glue logic |
| Crossplane | Provider CRDs | Cloud resource orchestration |
| Jsonnet/Tanka | Pure config | No runtime reconcile needed |
